Diagnóstico de guardado Flash / Ruffle

Esta página solo inspecciona el almacenamiento del navegador en el mismo sitio. No cambia ni borra partidas y no envía datos a ningún servidor.

Antes de analizar

  1. Abre el juego en otra pestaña del mismo dominio de GitHub Pages.
  2. Juega hasta que ocurra algo que normalmente se guarda (por ejemplo, avanzar en el tutorial o desbloquear algo) y espera unos segundos.
  3. Vuelve aquí y pulsa Actualizar diagnóstico.
  4. Si puedes, toma otro diagnóstico antes de jugar y compara las claves y tamaños.

No pegues aquí contraseñas, tokens ni claves privadas. El informe intenta mostrar nombres y tamaños, no el contenido completo de las partidas.
